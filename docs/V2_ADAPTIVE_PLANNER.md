# V2 Adaptive Planner

Priority combines weakness, unresolved errors, due reviews, urgency, score gap and a comfort-practice penalty. The result is 0–100 and includes human-readable reasons.

Daily prescription consumes an explicit minute budget. Blocks are added in priority order, then due error review and vocabulary review. It never exceeds `availableMinutes`; low-return work is deferred rather than padded into the plan.

The V2 macro plan remains historical context. The intended next layer is a rolling 7-day plan derived from the same priority output, while today's prescription remains the most immediate recommendation.
