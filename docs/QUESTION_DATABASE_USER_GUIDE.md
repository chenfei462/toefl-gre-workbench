# 题库与训练闭环使用说明

项目：`D:\systemDir\Desktop\toefl-gre-workbench`

启动：在项目目录运行 `npm install`，然后 `npm run dev -- --host 127.0.0.1`，打开 http://127.0.0.1:5173/ 。生产文件通过 `npm run build` 生成到 `dist`；网页托管需要将前端路由回退到 index.html。

## 每天怎么用

1. 今日处方查看优先技能和时间预算；底部查看、保存明日训练预览。结果变化后可以重新保存，不会删掉旧任务与练习记录。
2. 在官方来源或自己的资料中完成训练。题库目录提供 ETS 入口，登录和付费内容只保存引用。
3. 练习记录页选择来源和技能，输入总题数、正确数、用时及错因分布。20 题、10 错、词汇 7/逻辑 2/其余 1，会生成 20 条明确标记为批量汇总的作答与 10 道错题。
4. 只对错题补充题号、我的答案、参考答案和笔记；补充现有批次错题不会多生成一份作答。也可以用每页右上角“记录错题”直接保存单道来源引用。
5. 错题实验室完成原题二刷后，选择真实结果。失败重新打开；成功保留复盘记录并安排下一次间隔检查。8 对/2 错时二刷正确率为 80%。

## 题库

- 支持 JSON 文件、JSON 粘贴、CSV 文件、CSV 粘贴和手动引用录入。所有导入先预览，显示逐条错误、警告和重复，确认后才保存有效记录。
- CSV 模板可在导入弹窗下载。多选答案使用选项 ID，以 `|` 分隔，题号引用允许题干为空。
- JSON 支持已有 `answer` 字段，以及请求规格中的 `correctAnswer`、`answerVerification`、`verificationStatus` 别名。完整题目必须有题干和来源；ETS 来源默认只保存引用。
- 可筛选考试、科目、题型、技能、难度、来源、级别、版本，以及未做/做对/做错/到期/掌握状态。
- `/questions/latest` 默认显示当前格式、官方来源、已验证题目；按核验/发布日期排序，不按入库时间冒充最新真题。`/questions/import` 直接打开导入。
- 题目详情显示来源定位、答案验证状态和修改历史。人工校正会保存旧快照，不会被标成官方答案；历史作答保留但暂停计入掌握度。
- 初始样例是 ETS 公开 PDF 中两道 GRE 阅读题的定位和答案元数据；题干和官方解析在原始 PDF 中查看。它们不是完整模拟考试，也不是近期实考真题。
- 练习集优先薄弱技能、到期错题与维持训练；时间预算以每题约两分钟估计。只有两道匹配题时输出两道，不伪造额外题目。

## 真实性与保存

- 只有带 ETS 官方域名、ETS 发布者及已核验官方来源的记录显示 ETS Official。非官方来源不能导入声称官方的答案。
- 旧版题目被标为 legacy；当前练习不接受旧版格式或争议答案。社区回忆明确显示未验证，不会当作官方分数。
- 来源、选项 ID、作答、题目关联与 session ID 在刷新和学习备份恢复后保留。
- 题库、来源、文章、解析、媒体引用和答案修改历史通过独立 IndexedDB repository 保存；学习历史保持现有 localStorage adapter，当前题量无需迁移全部历史。
- **备份分两份**：设置页导出学习记录；题库页导出题库及关联资料。换设备时分别恢复。学习记录恢复需要替换确认；题库导入只新增并检测重复。
- 不同域名、端口或浏览器的数据彼此独立。正式部署后先导出开发地址的两份备份，再在新地址恢复。

## 来源核验

2026-10-11 查阅 ETS TOEFL 内容结构、备考入口、GRE POWERPREP 和公开样例 PDF。15 个目录记录提供官方 URL、版本范围、核验日期、来源级别和引用模式。部分旧 TestReady 产品仅保留目录入口；具体产品可用性及考试版本需在 ETS 账号内检查，不能由目录条目推断单题兼容性。
