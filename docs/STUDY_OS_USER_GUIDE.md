# Study OS 使用说明

本次升级继续使用原有 Question → Attempt → Error → Retry → Mastery → Priority → Prescription 内核。启动：`npm ci`，`npm run dev`。数据保存在当前浏览器。

## 日常训练
1. 设置中填写考试日期；首页处方依据真实作答、错题、复习和日期重算。点击「开始训练」带入考试、技能、时长。
2. 练习页从已有题库选择题目，可选前20题。作答、标记、题号和截止时间自动保存；刷新后倒计时继续。到时锁定答案，确认提交。
3. 已验证客观题自动核对；未答、未验证答案和主观题显示待评价。正确率不是官方分数。一次提交逐题产生 Attempt，错误自动进入 Error Lab，重复提交不重复记账。
4. Error Lab 可记录技能、错因、陷阱、错误推理、正确推理和下次策略。二刷保留完整历史；生词可直接加入对应考试词库。
5. 词汇页先回忆再显示词义，用 Again / Hard / Good / Easy 评分。FSRS 计算精确到时间的到期日；新学阶段可能在数分钟后再出现。空词义可在卡片展开后补充，补充前不可评分。旧词汇历史保留，首次使用时初始化 FSRS，不编造过去复习。
6. 晚间查看 Daily Study Loop，完成到期错题和词汇，查看并保存明日处方。历史来源于真实事件，勾选计划任务不会伪造作答证据。

## 口语
支持 Listen and Repeat 与 Take an Interview。输入自有题目；复述题需上传题目音频。播放后开始准备，允许麦克风，录音结束后复听、自评、标记八类问题。准备/回答时长可调整。自评是低权重学习证据，不是 AI 或官方评分。

音频保存在 IndexedDB，JSON 备份只包含 metadata。请用「下载录音」单独备份音频；换浏览器恢复 JSON 后，可为缺失音频上传之前下载的文件。保存失败时保留可下载的录音并禁用新训练，允许重试保存。麦克风需要支持 MediaRecorder 的浏览器和 HTTPS/localhost。

## 模考和最后一周
诊断与模考保存独立 MockSession：考试、来源、日期、分科分数、可选总分、条件和用时。可填写真实技能题量/答对数作为证据；仅有成绩不会伪造逐题正确率。官方模考、高质量分科测试、普通模考、社区题采用不同权重。分科测试无总分时保存分科 checkpoint，不合成总分。

考试日期在0–7天内自动进入 FINAL WEEK：优先临近考试、未解决错题和限时混合弱项练习。预算至少90分钟、距离考试超过1天且近3天没有该考试模考时，预留30分钟分科模考。混合选题交错不同题型/技能；题库不足时显示现有题，不虚构材料。

## 材料与备份
资料库可保存本人拥有、公开或授权的 TXT/PDF/DOCX/音频。TXT 支持文本阅读，音频可播放，PDF 可打开，DOCX 下载后用 Word 等程序阅读。PDF/DOCX 不自动抽题。单文件最多100MB，TXT最多5MB。

设置中的 JSON 导出/导入包含学习记录、练习快照、FSRS、口语metadata、模考及错题分析。题库仍使用题库页独立导出；材料和录音原文件应单独下载。导入需要确认，损坏数据保留原始恢复备份。浏览器存储失败会显示持续警告和当前数据导出入口。

## 验证
运行 `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`。首次 E2E：`npx playwright install chromium`，然后 `npm run test:e2e`。同一目录不要同时启动多个 Playwright 运行，避免共享产物目录和开发服务器相互干扰。
